# AD-2026 - Proyecto Final

## 💾 Fase 3: Implementación de SQL y Analítica Avanzada

En esta etapa del proyecto, trasladamos nuestro análisis a un entorno SQL. Este nivel no solo abarca consultas relacionales, sino que integra técnicas de **analítica avanzada** para extraer patrones predictivos y métricas complejas sobre el dataset procesado.

### Contenido de la Fase:
- **04_analisis_sql.ipynb**: Notebook central que documenta la implementación de consultas SQL con funciones de ventana (DENSE_RANK, RANK, LAG), expresiones condicionales (CASE WHEN) y subconsultas con HAVING para la extracción de métricas de negocio.
- **05_analitica_avanzada.ipynb**: Notebook dedicado a la construcción de un modelo de regresión (Gradient Boosted Trees) para predecir el monto de venta a partir de variables como cantidad, descuento y categoría del producto, incluyendo evaluación del modelo (RMSE, R²) e importancia de variables.
