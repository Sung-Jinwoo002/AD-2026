# AD-2026 - Proyecto Final: Análisis de Ventas

Proyecto integral de ingeniería de datos centrado en el análisis de rendimiento de ventas del dataset *Superstore*. El desarrollo se estructuró en tres fases incrementales para asegurar la calidad y profundidad del análisis.

## 🚀 Resumen del Proyecto
- **Fase 1: Ingesta y Limpieza**: Preparación del dataset crudo, eliminación de nulos, tratamiento de duplicados y estandarización de nomenclatura.
- **Fase 2: Análisis Exploratorio (EDA)**: Evaluación estadística, generación de KPIs clave (Ventas, Ganancias, Pedidos) y visualización mediante Dashboards interactivos en Databricks.
- **Fase 3: Implementación de SQL**: Aplicación de consultas relacionales para la extracción de métricas de negocio avanzadas.

---
### 🛠️ Estructura del Repositorio
Cada etapa del proyecto se encuentra organizada en sus respectivas ramas para facilitar la trazabilidad y revisión del flujo de trabajo de datos.
