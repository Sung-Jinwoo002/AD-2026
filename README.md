# AD-2026 - Proyecto Final

## 🛠️ Fase 1: Ingesta y Limpieza de Datos

En esta etapa inicial del proyecto, establecimos la base de datos necesaria para el análisis exploratorio, priorizando la integridad y calidad de la información.

### Contenido de la Fase:
- **ADTD - Proyecto Final.dbc**: Notebook de creación y carga inicial del dataset.
- **02_limpieza_datos.dbc**: Notebook dedicado al proceso de limpieza, incluyendo tratamiento de valores nulos, eliminación de duplicados y estandarización de nomenclatura de columnas.
- **superstore.csv**: Archivo de datos original (fuente cruda) utilizado para la ingestión inicial.
