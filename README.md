## 💾 Fase 3: Implementación de SQL y Analítica Avanzada

En esta etapa del proyecto, trasladamos nuestro análisis a un entorno SQL. Este nivel no solo abarca consultas relacionales, sino que integra técnicas de **analítica avanzada** para extraer patrones predictivos y métricas complejas sobre el dataset procesado.

### Contenido de la Fase:
- **04_analisis_sql.ipynb**: Notebook central que documenta la implementación de SQL. Incluye:
    - **Consultas Relacionales**: Extracción de métricas de negocio mediante joins y agregaciones complejas.
    - **Analítica Avanzada**: Aplicación de modelos estadísticos y técnicas de análisis de datos para identificar tendencias profundas, correlaciones y comportamiento de los clientes que complementan el EDA realizado en la Fase 2.
